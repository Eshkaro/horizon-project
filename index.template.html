This prototype establishes the portfolio baseline. Live call matching and an AI assistant are future work; this version does not generate funding recommendations.

Source & organisation matching

Exact organisation ID matching includes the Bocconi legal entity only. No affiliated entities are silently merged. CORDIS does not contain rejected applications. The separate proposal benchmark section uses Commission evaluation totals; it does not calculate a Bocconi-specific success rate.

Definitions & limitations

Funding is the sum of participant-level netEcContribution; zero is retained and missing values are reported separately. Coordinator counts use CORDIS roles. “Within project dates” means the reference date falls between start and end, excluding CORDIS terminated/cancelled projects and ended Bocconi participations. It is not confirmation of current project activity.

No annual cash flow is inferred from full-grant contributions. Ending-window amounts are full contributions of those grants, not funds remaining or money lost. CORDIS is a monthly snapshot and can differ from live project pages.

Next development milestones

Validate the baseline with a university funding adviser. Add open calls from the Funding & Tenders Portal, explainable matching rules and eligibility checks. Add an assistant that cites evidence and uses calculations performed by code.
